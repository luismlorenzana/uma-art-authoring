# Authoring rules

Read and follow `AGENTS.md` before repository work. Its owner-private restrictions apply to every AI session,
including Claude. Never view, render, search, scan, OCR, attach or extract text/metadata from private images,
prompts, generation histories, edit notes or actual approval records, locally or in cloud/browser views.

Never inspect `owner-private/`, `owner-only/`, `private-variants/`, `private-art-outbox/`, `art-private/`, files
containing `.private.`, or the previous personal studio. Keep game private mode off during agent work. Use only
the documented count-only `private-art` commands for approved opaque transfers; never run `private-art:owner`
on real owner files. Private content and prompts never enter git, agent context, logs or normal galleries.

Read `docs/private-art-variants.md` for the workflow. Repository instructions are conduct rules, not OS isolation.
